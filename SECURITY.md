# Security policy

This project is maintained for free, self-hosted WordPress use. The supported release is 0.1.0; check the release page for newer versions.

Report a suspected vulnerability privately through [GitHub's security advisory form](https://github.com/digicyfr/digicyfr-service-menu/security/advisories/new). Include the plugin version, WordPress/PHP versions, reproduction steps and impact. Please do not open a public issue with exploit details. Maintainers will acknowledge reports when available; no fixed response time is promised.

For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/digicyfr/digicyfr-service-menu/issues). This plugin sends no telemetry or automatic vulnerability reports.
