# Website copy — Digicyfr Service Menu 0.1.0

## English

**Title:** Digicyfr Service Menu

**Summary:** A free, open-source WordPress service catalog that editors can reuse across pages.

**What it does:** Maintain a service name, plain-text description, optional duration and price wording, categories, and order. Show published services with a block or shortcode. Archive a service to Draft and export a spreadsheet-safe review CSV.

**Tested environment:** WordPress 7.1, PHP 8.3.33. Declared minimum: WordPress 7.1, PHP 8.3. Compatibility with other versions has not been tested.

**Scope:** No booking, payments, tax or legal price-compliance claims. Each embed shows at most 100 services with a visible notice if more match. CSV is for human review, not automated import. Uninstall retains service data. Manual ZIP updates in 0.1.0.

## Polski

**Tytuł:** Digicyfr Service Menu — Lista usług

**Opis krótki:** Bezpłatna wtyczka WordPress o otwartym kodzie do tworzenia listy usług wielokrotnego użytku na stronach firmy.

**Funkcje:** Wprowadź nazwę usługi, opis zwykłym tekstem, opcjonalny czas trwania i treść ceny, kategorię oraz kolejność. Wyświetl opublikowane usługi w bloku lub krótkim kodzie. Archiwizuj usługę jako szkic i pobierz bezpieczniejszy dla arkuszy plik CSV do przeglądu.

**Przetestowane środowisko:** WordPress 7.1, PHP 8.3.33. Deklarowane minimum: WordPress 7.1, PHP 8.3. Zgodność z innymi wersjami nie była testowana.

**Zakres:** Bez rezerwacji, płatności, obliczeń podatku ani zapewnień prawnych dotyczących cen. Osadzona lista pokazuje najwyżej 100 usług i wyświetla informację, gdy pasuje więcej. CSV służy do ręcznego przeglądu, nie do automatycznego importu. Odinstalowanie zachowuje dane usług. W wersji 0.1.0 aktualizacje odbywają się ręcznie przez plik ZIP.
